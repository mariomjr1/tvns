# TVNS Pipeline — Standard Operating Procedures (SOPs)

This folder contains one SOP per pipeline step. Each SOP is a self-contained
operator's checklist: **purpose, prerequisites, inputs, the exact command,
parameters, outputs, QC checks, troubleshooting, and the next step.**

## Protocol reference files

The acquisition evidence used for protocol/task decisions is stored under
[`protocols/`](protocols/):

- [`Bay1_tvns_tasks_only.pdf`](protocols/Bay1_tvns_tasks_only.pdf) — Siemens Terra
  protocol pages for the original BlockStim/ContinuousStim acquisition.
- Six real BIDS BOLD JSON sidecars from two subjects, covering rest, BlockStim,
  and ContinuousStim.

The sidecars document both the pre-update Terra/E12 sequence and the post-update
Terra.X/XA60 CMRR sequence. See
[`PROTOCOL_TASK_REEVALUATION_2026-06-10.md`](PROTOCOL_TASK_REEVALUATION_2026-06-10.md)
for the interpretation and task implications.

Run the steps in order. **NEW ORDER (RETROICOR → fMRIPrep):** physiological noise is
removed in native space (steps 02 → 03 → 04) *before* fMRIPrep (step 05) runs on the
corrected image. Step 01 is per study; the physiological branch (02–04) is per subject;
fMRIPrep (05) is per study; the stimulus/first-level branch (06 → 07) is group-level.
The first-level GLM models the (physio-cleaned) fMRIPrep BOLD with stimulus + motion/FD
regressors only.

## Conventions used in every SOP

- **Raw scanner ID** — e.g. `7T1019HC_042726` (with underscore). One per line in
  `utility/SubjectList.txt`.
- **BIDS ID** — e.g. `sub-7T1019HC042726` (underscores stripped, `sub-` prefix).
  Generated by Step 02 Part 1 into `utility/SubjectListBIDS.txt`.
- **Project root** (default lab path): `/autofs/cluster/vagabond/USERS/MARIO/Projects/lyme`
  - `rawdata/` — downloaded DICOMs
  - `sourcedata/` — BIDS dataset + `.heudiconv/`
  - `sourcedata/derivatives/` — `fmriprep/`, `physio/`, `spm/`
- Every script prints usage when run with no/insufficient arguments, and accepts
  all paths as positional arguments, so the defaults below can be overridden for
  a new project.

> **Design note (read once).** RETROICOR is applied as a **slice-wise image correction
> in native space BEFORE fMRIPrep** (steps 02–04); fMRIPrep (step 05) runs on the
> corrected BOLD. The first-level GLM (Step 07) models that physio-cleaned BOLD with
> stimulus + motion/FD regressors only — no RETROICOR regressors. This is the
> field-standard order (AFNI `ricor` before `volreg`) and avoids collapsing
> slice-specific regressors onto the T1w-resampled BOLD.
